# The portfolio is an instrument, not a page

The portfolio is a single physical unit rendered in real-time WebGL and viewed top-down, on one
screen with no page scroll. Content lives inside the Unit's own Screen and is paged by pressing
hardware. This is the whole thesis: Fernando has no case studies, so the artifact itself has to be
the proof of craft, and a scrolling document cannot be that.

**Rejected alternative**: a conventional scrolling portfolio site with a WebGL hero (the July
"Monument" direction, archived under `docs/archive/`). Rejected because the scene became decoration
beside the content instead of being the content, and every section below it was a claim without
evidence.

**Consequences**: no route-based navigation, no scroll-driven anything, no growth by adding
sections. New content must fit inside an existing Module or justify a new Part.
